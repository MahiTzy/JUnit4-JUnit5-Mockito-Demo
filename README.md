# JUnit 4, JUnit 5 and Mockito Demo

A Java testing project demonstrating unit-testing tools and mocking techniques.

## Overview
This repository is intended to provide examples of automated tests using JUnit and Mockito. Review the test packages and build configuration for the exact scenarios and versions.

## Technology
- Java
- JUnit 4 and/or JUnit 5 as declared by the build
- Mockito

## Getting Started
1. Install a compatible JDK.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/JUnit4-JUnit5-Mockito-Demo.git
   cd JUnit4-JUnit5-Mockito-Demo
   ```
3. Import the project into your Java IDE or resolve dependencies using the configured build tool.
4. Run the test suite using the build tool's test task (for Maven, commonly `./mvnw test` when the wrapper exists).

## Learning Focus
Explore assertions, test lifecycle, test isolation, mocks, stubs, and verification as demonstrated by the test cases.

## Development
Add tests alongside the relevant application code and keep tests deterministic and independent.
